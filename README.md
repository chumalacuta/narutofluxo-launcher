# NarutoFluxo Launcher

**Versão 2.2.5 · Windows 64 bits**

### [⬇ Baixar o instalador](https://github.com/chumalacuta/narutofluxo-launcher/releases/latest)

1. Na página de download, abra **Assets** e baixe o arquivo **.exe**.
2. Execute o instalador e abra o **Fluxo Launcher**.
3. Entre com seu **nick** ou sua **conta Microsoft** e clique em **Jogar**.

Os mods e as texturas já estão incluídos. As atualizações são verificadas pelo próprio launcher.
